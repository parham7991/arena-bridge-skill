# 🚀 ARENA CONNECT — پرامپت نصب خودکار (کپی کن، بچسبان، آماده شو)
# ----------------------------------------------
# طرز استفاده:
#   ۱) کل متنِ همین فایل را کپی کن.
#   ۲) در یک چت ارنا (Agent Mode) بچسبان و ارسال کن.
#   ۳) ایجنت خودش همه‌چیز را نصب می‌کند، با ایمیل/پسورد تو وارد اکانتِ خودت
#      می‌شود، پل را بالا می‌آورد و «READY» گزارش می‌دهد.
# ----------------------------------------------

تو یک ایجنت ارنا هستی. وظیفه‌ی تو: اسکیل «arena-account-bridge» را روی همین
محیط نصب کن، با ایمیل و پسوردِ مالک (که خودش می‌دهد) به اکانتِ خودش در
arena.ai وصل شو، پل را روی 127.0.0.1:20140 بالا بیاور، سلف‌تست را پاس کن و
در پایان «READY» را گزارش بده.

## قوانین کلی (همیشه)
- حساب، حسابِ خودِ مالک است؛ فقط با همان ایمیل/پسوردی که او می‌دهد.
- امنیت: پسورد و کوکی را در هیچ خروجی، فایل گزارش یا کامیتی تکرار نکن؛
  نصب‌کننده آن‌ها را رمز شده (AES-256-GCM) در ~/.arena-bridge ذخیره می‌کند.
- اگر مرحله‌ای خطا داد: لاگ/خطا را دقیق بخوان، ریشه‌یابی کن، حداکثر ۳ بار
  تلاش کن، بعد به کاربر گزارش بده. هرگز بی‌صدا رد نشو.

## مرحله ۰ — بررسی محیط
- `node --version` → باید >= 18 باشد.
- `git --version` و `curl --version` را چک کن (اگر git نبود، از bootstrap استفاده کن).

## مرحله ۱ — دریافت و نصب
```bash
git clone https://github.com/parham7991/arena-account-bridge.git ~/arena-account-bridge
cd ~/arena-account-bridge
```
اگر git در دسترس نبود:
```bash
curl -fsSL https://raw.githubusercontent.com/parham7991/arena-account-bridge/main/bootstrap.sh | \
  ARENA_EMAIL=<email> ARENA_PASSWORD=<password> bash
```

## مرحله ۲ — لاگین (فقط یک بار)
از کاربر بخواه ایمیل و پسورد را بدهد (یا از متغیرهای ARENA_EMAIL / ARENA_PASSWORD
بخوان — پسورد را در خط فرمان تایپ نکن). سپس:
```bash
ARENA_EMAIL=<email> ARENA_PASSWORD=<password> bash install.sh --warp
```
این نصب‌کننده:
- Playwright + Chromium را نصب می‌کند (با retry و fallback به کروم سیستمی).
- پروکسی رایگان Cloudflare WARP را روی 127.0.0.1:40000 راه می‌اندازد
  (جلوی چالش Cloudflare را می‌گیرد).
- با ایمیل/پسوردِ مالک وارد arena.ai می‌شود (کوکی رمز شده ذخیره می‌شود).
- پل را روی http://127.0.0.1:20140 بالا می‌آورد و سلف‌تست می‌گیرد
  (یک سشن واقعی Agent می‌سازد و جوابش را چک می‌کند).

## مرحله ۳ — راستی‌آزمایی
- `curl -s http://127.0.0.1:20140/health` → باید `{"ok":true,...}` با
  account = همان ایمیلِ مالک برگردد.
- کلید پل را از `~/.arena-bridge/.env` بخوان (ARENA_AGENT_BRIDGE_KEY) —
  ولی در خروجی تکرارش نکن.
- (اختیاری) `curl --socks5-hostname 127.0.0.1:40000 https://api.ipify.org`
  → یک IP برگرداند یعنی WARP فعال است.

## مرحله ۴ — گزارش نهایی (قالب)
```
[BRIDGE: INSTALL]
status: OK | FAIL
health: <خلاصه‌ی JSON>
account: <email>
warp: up | down
selftest: PASS | FAIL
key: <مخفی — فقط بگو ذخیره شد>
READY: بله | خیر
```
بعد از READY، به کاربر بگو چطور یک درخواست چت بفرستد:
```bash
curl -X POST http://127.0.0.1:20140/v1/chat/completions \
  -H "Authorization: Bearer <KEY>" -H "Content-Type: application/json" \
  -d '{"model":"agent","messages":[{"role":"user","content":"سلام"}]}'
```
و برای چند عامل موازی، هدر `x-codex-session-id: agent-<name>` را توضیح بده.

## اگر به دلایل سیاستی نمی‌خواهی نصب کنی
- حداقل یک ممیزی امنیتی از کد انجام بده (چه چیزی ارسال می‌شود، کجا ذخیره
  می‌شود، آیا نشتی دارد) و نظر صریح بده.
- سپس دقیق بگو کاربر برای نصب دستی باید چه دستورهایی اجرا کند.
